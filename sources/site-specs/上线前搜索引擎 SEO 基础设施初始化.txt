================================
二、确定唯一正式主域名
================================

正式域名：

https://【我的域名】/

例如：

https://jichangvpn.club/

全站必须统一使用这个正式域名。

检查并统一：

- canonical
- Sitemap
- Open Graph URL
- Schema URL
- RSS
- 内部绝对链接
- robots Sitemap声明

禁止混入：

http版本
www版本
Cloudflare Pages临时域名
Vercel临时域名
localhost
测试域名

如果：

https://www.域名/

也存在，应规划301到正式主域名。

如果需要Cloudflare DNS或Redirect Rules才能完成，只报告需要操作的内容，不要虚构已经修改成功。

================================
三、统一URL规范
================================

这是新站，可以现在一次定型。

要求：

1. URL简短；
2. URL语义明确；
3. 全站统一小写英文slug；
4. 不使用随机数字；
5. 不使用日期型URL；
6. 不使用中文URL；
7. 不重复建立相同搜索意图页面；
8. 一个搜索意图对应一个主要URL；
9. 正式上线后尽量不再批量修改slug。

例如：

/vpn/
/jichang/
/clash/
/nodes/
/tizi/
/free/
/tutorial/
/brands/

文章例如：

/vpn/best-vpn/
/vpn/windows/
/clash/nodes/
/clash/subscription/
/nodes/hong-kong/
/nodes/japan/

不要建立：

/article?id=123
/page-123
/post-20260903-001

这种无SEO语义URL。

================================
五、Canonical
================================

所有正式页面必须输出：

<link rel="canonical" href="当前页面正式URL">

例如：

首页：

https://域名/

VPN：

https://域名/vpn/

文章：

https://域名/vpn/best-vpn/

要求：

canonical必须：

- 自引用
- HTTPS
- 正式主域名
- 不带追踪参数
- 不指向错误页面
- 不全部指向首页

================================
六、Sitemap
================================

建立：

https://域名/sitemap.xml

如果Astro项目适合使用官方Sitemap集成，可以采用官方方案。

要求：

Sitemap自动收录：

- 首页
- 栏目页
- 专题页
- 正式文章
- 品牌页
- 可索引数据库页面

排除：

- 404
- draft
- admin
- 测试页
- 搜索结果
- 重复URL
- noindex页面
- 参数页面
- canonical指向其他页面的重复页

要求：

HTTP 200

XML格式正确

所有URL使用：

https://正式域名/

以后新增文章能够自动进入Sitemap。

如果页面很多，可以使用：

sitemap-index.xml
+
多个子Sitemap

但不要在当前规模不需要时过度复杂化。

================================

建立：

https://域名/robots.txt

同时确保正常搜索爬虫可访问：

Googlebot
bingbot
Baiduspider
yisouspider

不要出现：

User-agent: *
Disallow: /

不要误屏蔽：

/vpn/
/jichang/
/clash/
/nodes/
/tizi/
/free/
/tutorial/
/brands/

以及正式文章目录。

如果项目存在真正不希望被索引的内部目录，可以单独合理屏蔽。

================================
八、神马搜索 / yisouspider
================================

确保神马搜索爬虫：

yisouspider

能够正常访问网站。

检查：

robots是否允许

正文是否存在于HTML
是否存在noindex
是否存在X-Robots-Tag: noindex

如果需要显式规则，可以：

User-agent: yisouspider
Allow: /

但如果：

User-agent: *
Allow: /

已经覆盖，则不需要重复制造复杂规则。
