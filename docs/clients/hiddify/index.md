## 2. Hiddify 全平台特性与五步新手配置实操

### 1. 全平台通用性与新手友好定位

<strong>Hiddify</strong>（Hiddify App）是目前少数同时覆盖桌面三端与移动双端的持续活跃开源项目之一。它以高性能 <code>sing-box</code> 为底层核心，却屏蔽了原生 sing-box 繁琐的 JSON 手写门槛，能够自动解析常见机场下发的 Clash YAML、V2Ray 订阅链接与 sing-box 配置，并提供一键“自动选择最低延迟节点”能力，在《2026 机场代理客户端大全》中被列为桌面与移动端的新手友好代表。

> [!IMPORTANT]
> <strong>分流策略核验提示</strong>（依据 <code>data/clients.json</code>）：Hiddify 在<strong>不同订阅格式转换时建议核对分流规则默认策略</strong>。首次安装后若未将地区设为中国（China），可能导致国内 App 与网站同样经过海外代理转发，引起延迟飙升与流量快速消耗。

### 2. 五步新手上手与排障实操

1. <strong>从官方渠道获取对应版本</strong>：桌面端与 Android 从官方 GitHub Releases 下载对应架构包；iOS 端需在非国区 App Store 搜索安装（实际可用性以所属地区商店为准）。
2. <strong>先设定地区路由策略再连接</strong>：进入“设置 → 配置选项”，确认地区（Region）设置为 <strong>China (zh)</strong>，确保内置大陆域名与 IP 直连分流规则正确激活。
3. <strong>一键添加机场订阅链接</strong>：点击首页“+ 新增配置文件”，粘贴机场提供的通用订阅链接（支持剪贴板导入或扫码），等待解析完成。
4. <strong>按需求切换代理模式与节点</strong>：日常网页与 App 使用默认 <strong>System Proxy（系统代理）</strong>或移动端 <strong>VPN</strong> 模式即可；需要终端/全流量接管可在桌面端切换为 <strong>TUN（VPN 服务）</strong>模式。默认自动选择（Auto）会自动挑选延迟较优节点，亦可手动展开列表指定香港、日本或美国解锁节点。
5. <strong>核对策略组差异</strong>：由于 Hiddify 会将外部 Clash 订阅统一转换为 sing-box 运行配置，若你需要精确复刻机场定制的复杂策略组名称，可搭配 <a href="/clients/clash-verge-rev/">Clash Verge Rev</a> 或 <a href="/clients/flclash/">FlClash</a> 使用。

## 3. 规则配置、TUN 模式与高频故障排查索引

在完成基础订阅导入后，若遇到分流不准、命令行直连、DNS 污染或节点全部超时等常见现象，可按以下官方排障路径逐项核查：

- <strong>订阅导入与转换标准流程</strong>：参见 <a href="/guides/subscription/">订阅导入与客户端配置指南</a>，确认 Clash YAML、Base64 与 sing-box JSON 格式边界。
- <strong>规则分流与策略组调优</strong>：参见 <a href="/guides/clash-rules/">Clash 分流规则配置指南</a>，避免国内常用网站走代理消耗流量或导致支付异常。
- <strong>TUN 虚拟网卡与 DNS 防泄漏</strong>：参见 <a href="/guides/tun-dns/">TUN 模式与 DNS 分流指南</a>，解决终端命令行、游戏与系统组件代理接管问题。
- <strong>高频故障快速定位</strong>：遇到拉取报错查看 <a href="/troubleshooting/subscription-failed/">订阅失败与更新报错排查</a>；遇到全节点超时查看 <a href="/troubleshooting/node-timeout/">节点超时与全部不可用排查</a>；遇到国内网站打不开或 DNS 异常查看 <a href="/troubleshooting/tun-dns-error/">TUN 异常与 DNS 污染排查</a>。
- <strong>封闭生态风险评估</strong>：选购仅限自研客户端品牌前，务必阅读 <a href="/risks/exclusive-client-lockin/">专属客户端锁定风险解析</a> 与 <a href="/clients/compatibility/">31 家机场客户端兼容性矩阵</a>。
