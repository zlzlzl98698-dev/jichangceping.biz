### 60GB 月度配额实战调优与排障清单

1. <strong>防偷跑流量分流配置</strong>：60GB/月折合每天约 2GB，若开启全局代理极易被系统更新、网盘同步或国内视频消耗殆尽。务必严格按照 [Clash 分流规则教程](/guides/clash-rules/) 启用 Rule 规则模式，将国内直连（<code>DIRECT</code>）与高流量媒体域名分流隔离。
2. <strong>订阅更新失败或节点列表为空</strong>：参考 [订阅失败与更新报错排查](/troubleshooting/subscription-failed/) 与 [订阅导入教程](/guides/subscription/) 检查系统代理残留及 DoH 设置。
3. <strong>VLESS 节点超时或 TUN 断网</strong>：对照 [节点超时与不可用排查](/troubleshooting/node-timeout/) 校准本地系统时间（TLS 对时间偏差敏感），并使用 [TUN 模式与 DNS 污染排查](/troubleshooting/tun-dns-error/) 核对 Fake-IP 与国内直连 DNS。
