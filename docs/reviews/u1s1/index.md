## 三、IPLC 专线架构与地区节点覆盖

<NetworkTopology slug="u1s1" />

U1S1 将自身基础设施定位为 <strong>IPLC 专线（International Private Leased Circuit）</strong>，覆盖 <strong>香港、台湾、新加坡、日本、美国</strong> 五个核心落地地区。相比纯公网中转机场，IPLC 专线在跨境段采用运营商级点对点私有链路，通常能规避国际公网出口在晚间高峰期的大规模丢包与 QoS 限速。

不过，关于节点层面仍有两点需要理性看待：
- <strong>精确节点数待核实</strong>：资料并未说明五个地区各自部署了多少个入口与落地节点，也未标注是否存在高倍率节点（例如 2x/3x 倍率）或原生住宅 IP 专项说明。
- <strong>2000Mbps 带宽口径</strong>：厂商宣称 2000Mbps 带宽通常指单服务器端口或集群接入峰值能力，不等同于单用户单线程在任意运营商网络下都能跑满 2Gbps。真实可用带宽仍需结合下方两批次测试样本来看。
