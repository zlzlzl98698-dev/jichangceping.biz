### 2. 强制专属客户端的部署边界与排障直达

隐形人属于严格的 **`exclusive-only`（仅限自带客户端）** 形态，仅覆盖 [Windows](/clients/windows/)、[macOS](/clients/macos/)、[iOS](/clients/ios/) 与 [Android](/clients/android/) 消费端，**不提供任何第三方订阅链接**——这意味着 [Clash Verge Rev](/clients/clash-verge-rev/)、[Shadowrocket](/clients/shadowrocket/)、[v2rayN](/clients/v2rayn/) 以及 [OpenWrt](/clients/openwrt/)（[OpenClash](/clients/openclash/) / [PassWall2](/clients/passwall2/)）均无法导入使用，且设备同时在线数量随具体套餐档位浮动（并非全线不限设备）。相比同属自研客户端起家但保留通用订阅导入的 [光速云](/reviews/guangsuyun/) 与 [梯子云](/reviews/tiziyun/)，隐形人在多端扩展性与软路由兼容上明显受限，购前可对照[客户端兼容性总表](/clients/compatibility/)评估自身设备栈。

**使用专属客户端时的常见排障指引**：
- **客户端登录后节点拉取失败或列表空白**：如遇到官网登录/更新接口被本地 ISP 劫持或双域名前缀跳转问题，可先参考[订阅失败与更新报错排查指南](/troubleshooting/subscription-failed/)排查本地系统代理残留与 DNS 环境。
- **连接后部分地区节点超时**：因无公开测速截图，首次使用若发现个别节点卡顿或握手超时，按[节点超时与不可用排查指南](/troubleshooting/node-timeout/)切换节点并核对系统时间同步。
- **桌面端开启内置代理/TUN 后本地业务断网**：参考[TUN 模式与 DNS 污染排查指南](/troubleshooting/tun-dns-error/)排查与其他企业 VPN 或杀毒软件虚拟网卡的冲突。
