## 三、如何正确使用本档案库？

1. **看冲突不恐慌，但结算必核对**：大多数 `SOURCE_CONFLICT` 源于机场在不同季度调整了入门包容量或更换了订阅协议，只需在官网下单页确认当前实时参数即可。
2. **对 `elevated` 品牌提高门槛**：对于尚无独立测速截图或属于历史归档的品牌，在完成最新实测补全前，优先考虑证据完整度为 `high` 的已测品牌，详见 [测速与性能证据库](/benchmarks/) 与 [替代方案指南](/risks/alternatives/)。
