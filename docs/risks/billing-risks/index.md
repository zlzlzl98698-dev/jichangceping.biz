# 年付、不限时流量包与免费机场的账单风险深度解析

<strong>核心结论（Answer-First）：</strong> 基于本站 219 个真实套餐条目与 31 家风险审计记录，没有任何一家收录品牌提供经验证的无条件退款保障；购买策略应严格遵循 <strong>“新品牌首单仅买月付试水、轻度备用可选 ¥79–¥137 入门年付或 ¥99–¥147 百元不限时包、绝不囤积近千元超大一次性流量包或超低价多年付、彻底远离免费/合租订阅”</strong>。

在 <code>data/plans.json</code> 收录的 <strong>219 个真实套餐条目</strong> 中，计费模式主要涵盖 <strong>月付（87 档）、季/半年付（33 档）、年付（39 档）、两年/三年付（24 档）</strong> 以及 <strong>一次性不限时流量包（36 档，¥99–¥1199）</strong>。不同付款方式对应的资金风险敞口相差十倍以上。

## 三、退款现实与支付渠道注意事项

1. <strong>默认按“不支持退款”做预算决策</strong>：
   - 在数字订阅与网络加速领域，由于节点列表和订阅链接一旦下发即可被复制保存，绝大多数商家均执行严苛的不退或高折损退费规则。
   - 本站风险库 <code>data/risk-records.json</code> 中，<strong>光速云</strong>公开写明“特殊商品不支持退款”；其余 30 家品牌均无经核实的自由退款承诺（且隐形人、一翻云、SOGO 云等明确标注无免费试用）。切勿抱有“先花几百块买一年，不好用再找客服退”的侥幸心理。
2. <strong>注意优惠码的不适用例外条款</strong>：
   - 许多机场的新人优惠券明确排除了特价年付小包与永久流量包。例如光速云的 <code>AMM</code> 优惠码标注“轻量版 ¥99/年 与 147 永久套餐不打折”；多家品牌在促销文档与结算页之间也存在口径冲突（全库 31 家中多达 24 家存在文档口径冲突记录）。结算前务必以官网结账页实付金额为准。
3. <strong>留意“推广域名多版本”与链接格式异常</strong>：
   - 部分品牌在不同渠道存在多个推广域名前缀或缺少 <code>#/</code> 路由片段（例如风险库记录了云界线、环球梯等链接格式异常提示）。访问注册前务必核对浏览器地址栏域名与 HTTPS 证书是否有效，谨防进入高仿钓鱼站点充值。
4. <strong>加密货币（USDT）支付的不可逆性</strong>：
   - 部分品牌（如光速云、Firefly、灵动云、边缘节点 EdgeNova 等）支持 USDT 支付。链上转账一旦确认不存在任何平台申诉追回机制，且须仔细核对网络类型（TRC20 vs ERC20/BEP20）与矿工费，防止少转或转错链丢币。

## 四、为什么必须远离“免费机场”与“二手合租/破解订阅”？

1. <strong>免费机场 / 公开爬虫节点池</strong>：
   - 服务器与专线带宽不会凭空产生。免费节点池除了极高丢包率和秒封 IP 外，恶意搭建者可在落地端轻易记录所有非 HTTPS 明文通信、嗅探 DNS 访问轨迹，甚至针对特定网站实施中间人证书诱导或将用户设备变成共享出口节点。
2. <strong>闲鱼 / 社群低价“合租机场账号”或“共享订阅”</strong>：
   - 多人共用同一条订阅 Token 极易触发机场后端的<strong>异常并发 IP 封禁（直接封号清零不退费）</strong>；
   - 更严重的是，合租组织者可以在后台清晰看到账号的总流量消耗时段甚至部分审计触发记录。以目前正规入门年付低至 <strong>¥6.66–¥9/月</strong> 的真实价格水平（详见 [平价高性价比机场横向对比](/compare/budget-airports/)），完全没有任何必要为了省几块钱去承担封号与隐私风险。
