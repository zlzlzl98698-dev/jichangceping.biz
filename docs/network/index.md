# 线路与节点技术总览：穿透营销术语，看懂跨境代理三段式架构

<strong>核心结论（Answer-First）：</strong> 一条机场节点的实际体验，由<strong>“三段式链路”</strong>共同决定：<strong>第一段是您家宽带（电信/联通/移动）到国内中转入口的接入质量（BGP 多线或分网入口）；第二段是国内入口到海外机房的过境通道（IEPL / IPLC 内网专线 vs 公网中转）；第三段则是海外落地机房的国际带宽与 IP 纯净度（决定吞吐上限与 AI/流媒体解锁）</strong>。在全库 31 家收录品牌中，有 26 家在资料中声明采用 IEPL 或 IPLC 专线，但仅有 <strong>16 家保留了可核查的第三方测速截图</strong>。理性选型不能只看是否写了“IEPL”四个字母，而必须结合<strong>实测 RTT 延迟、晚高峰吞吐、节点倍率规则与异常节点比例</strong>综合判断。

## 一、机场跨境链路的三段式工程模型

当我们拆解 `data/network-routes.json` 中 31 家品牌的拓扑结构时，任何一条代理连接都遵循以下三段流程：

### 第一段：用户终端 → 国内接入层（Client to Entry）
- **核心痛点**：中国电信（CT）、中国联通（CU）、中国移动（CM）及广电/教育网之间的跨网互联瓶颈。
- **技术方案**：
  1. **三网 BGP 汇聚入口**：入口服务器本身拥有 BGP 多线带宽，电信、联通、移动用户均能以 5ms–25ms 的省内/邻省低延迟接入（如唯兔云、宇宙云、SOGO 云、全球云、暮光加速等在资料中强调三网优化或 BGP 智能调度）。
  2. **分运营商专用入口**：部分品牌会专门划出“电信专用节点”，例如 **[光速云](/reviews/guangsuyun/)** 在 2026-08-19 70 节点订阅中除了 60 个常规 VLESS 节点外，单独配置了 **10 个电信 AnyTLS 节点** 以针对性优化电信接入。

### 第二段：国内入口 → 海外边界（Transit / Cross-Border）
这是区分“直连机场”“公网中转机场”与“专线机场”的核心层级：
- **公网直连（Direct）**：无国内入口，客户端直接连海外 IP。成本最低，但在晚高峰（20:00–23:00）与特殊时期极易遭遇国际出口拥塞与端口阻断。
- **公网中转 / 隧道转发（Relay）**：经国内云服务器通过公网或优化线路（如 CN2 GIA / CMI / 9929）转发至海外（如灵猫网络明确标注为“中转优化线路”，飞猫云为“专线/中转混合”）。
- **IEPL / IPLC 内网专线（Dedicated Private Line）**：通过广港（深港）、沪日、沪港等企业级二层以太网（IEPL）或点对点电路（IPLC）过境，数据包在过境段不经过公网防火墙与公共国际出口排队，典型深港过境增量延迟仅 **2ms–5ms**。详见 [IEPL 与 IPLC 专线深度解析](/network/iepl-vs-iplc/)。

### 第三段：海外落地出口 → 目标服务（Exit to Target）
专线只管“把数据包送出境”，到了香港、日本或新加坡之后能不能跑满 500Mbps、能不能打开 ChatGPT 和 Netflix，完全取决于第三段**落地机房（Exit ASN）**：
- **商业大带宽机房 IP（Datacenter ASN）**：带宽充裕（单节点常见 1Gbps–2.5Gbps，甚至测试环境跑出 400–547MB/s），适合 4K 视频缓冲与大文件下载，但容易被 OpenAI、Claude、TikTok 标记为机房 IP。
- **原生 IP / 住宅商宽 IP（ISP / Native IP）**：IP 注册归属地与实际广播地一致（如一翻云强调原生住宅 IP，光速云、微风网络、Firefly 强调原生稳定节点），流媒体解锁更顺畅，但单机带宽成本更高。

## 三、节点倍率（Traffic Multiplier）与隐藏成本计算

在浏览机场节点列表时，节点名称后常带有 `1x`、`1.5x`、`2x`、`0.1x` 等倍率标识：

| 倍率类型 | 计费含义 | 典型应用场景 | 选型与配置建议 |
| :--- | :--- | :--- | :--- |
| **全节点 `1.0x`（标准倍率）** | 实际用 1GB 扣 1GB | 光速云极速版、星岛梦全线、无忧链接全线 | **最推荐**，流量账单直观透明，不怕自动测速误切高倍率节点 |
| **高倍率专线 (`1.5x` – `3.0x`)** | 实际用 1GB 扣 1.5–3GB | 部分机场的 IPLC 核心节点或冷门家宽节点 | 若挂着 `2x` 节点看 4K 视频，100GB 套餐实际只能用 50GB |
| **低倍率下载线 (`0.1x` – `0.5x`)** | 实际用 1GB 扣 0.1–0.5GB | 夜间闲时或大带宽直连/中转下载节点 | 适合拉取大型开发镜像或 Steam 更新，但延迟通常高于专线 |

> **工程防坑提醒**：如果您使用的机场包含 `2x` 或 `3x` 高倍率节点，务必在 [Clash Verge Rev](/clients/clash-verge-rev/) 或 [Shadowrocket](/clients/shadowrocket/) 的自动测速组中通过正则过滤排除高倍率节点，否则后台自动选路可能一夜耗光月度配额。

## 四、传输协议与线路架构的协同关系（VLESS / Shadowsocks / Trojan / Hysteria 2 / AnyTLS）

在实际测评中，很多用户容易把<strong>“线路类型（IEPL/IPLC/BGP）”</strong>和<strong>“传输协议（VLESS/SS/Trojan）”</strong>混为一谈。实际上，线路是物理或内网“高速公路”，协议则是跑在公路上的“加密封包格式”：

| 传输协议 | 在 31 家品牌库中的应用情况 | 与专线 / 中转搭配的工程特点 | 审计发现的真实协议冲突 |
| :--- | :--- | :--- | :--- |
| **Shadowsocks (SS)** | 光速云、飞猫云、星岛梦、二猫云、唯兔云、U1S1、灵猫网络、极连云、光年梯、一翻云、SOGO 云、可信云、速界、全球云（14 家） | 在 IEPL/IPLC 内网专线内部传输开销极小、吞吐效率高、客户端兼容性最广（2026-08-11 13 张 MAI-TEST-BOT 截图与光速云 08-19 三网 62 节点图均显示为 Shadowsocks） | 星岛梦、二猫云、唯兔云、光年梯、SOGO 云、可信云、速界在品牌文案中写 VLESS 或 Trojan，但 08-11 实测图显示为 Shadowsocks |
| **VLESS (含 Reality)** | 光速云、微风网络、大佬云、二猫云、无忧链接、Firefly、宇宙云、光年梯、一翻云、SOGO 云、可信云、速界、5.6元平价组、梯子云、灵动云（20 家） | 无冗余加密开销，配合 Reality / XTLS 在公网中转与专线接入端均具备优异的握手抗检测能力；在 9Gbps 后端下（光速云 08-19 VLESS、微风 07-19、无忧 07-18）实测单节点吞吐可达 375–547MB/s | 需使用 Mihomo（Clash Meta）、sing-box、Xray 或 Shadowrocket 等现代内核客户端，旧版原版 Clash Premium 不支持 VLESS |
| **Trojan** | 星岛梦、唯兔云、全球云、灵动云（4 家标注） | 标准 TLS 握手伪装，特征与常规 HTTPS 网站一致 | 灵动云站点文案混提 VLESS/Trojan，实测为 VLESS；星岛梦与唯兔云 08-11 实测图显示为 SS |
| **Hysteria 2** | [一翻云](/reviews/yifan/)（明确标注 Hysteria 2 + VLESS-Reality + SS 三协议） | 基于定制 QUIC/UDP 拥塞控制，专为高丢包或高延迟跨洋链路设计 | 部分国内地区运营商对高频 UDP 流量存在 QoS 限制，需与 TCP 协议互补使用 |
| **AnyTLS** | [光速云](/reviews/guangsuyun/)（2026-08-19 70 节点批次含 10 个电信 AnyTLS 节点） | 面向特定运营商（如中国电信）优化 TLS 填充与长连接特征的新兴协议 | 在 08-19 解锁图中，电信 AnyTLS 专用节点在珠海联通测试端多数显示 N/A，需在对应电信宽带或支持 AnyTLS 的新版客户端（如 Clash Verge Rev）中使用 |

## 常见问题 FAQ

### Q1：机场宣传里的“IEPL 专线”“IPLC 专线”和“BGP 中转”到底有什么区别？
普通直连是由用户本地宽带直接过公网国际出口连海外机房，晚高峰极易阻塞；BGP 中转是在国内部署多线接入机房（同时接电信/联通/移动），汇聚后再通过优化跨境线路转发；IPLC（国际私用租用电路）与 IEPL（国际以太网专线）则是在深圳-香港、上海-日本或沪港等节点间租用物理或二层以太网内网专线过境，不走普通公网国际出口，因此延迟抖动与丢包率通常更低。

### Q2：为什么本站所有品牌的线路拓扑图都会标注“厂商声明架构示意图”？
因为任何外部测评者都只能通过客户端连接入口 IP 与探测最终落地出口 ASN（如香港 HKT、日本 NTT、美国 Cogent），而无法在未获运营商机房授权的情况下从外部直接验证中间过境段到底是物理 IPLC 还是公网隧道中转。遵循实事求是原则，本站将跨境传输层统一注明为“厂商声明架构示意”，并结合三网实测延迟与吞吐辅助佐证。

### Q3：为什么同一家机场在电信、联通、移动三条宽带下的节点速度差距很大？
这取决于该机场在国内接入层（Entry Node）是否部署了真正的三网 BGP 入口或分网入口。例如在光速云 2026-08-19 62 节点 Shadowsocks 三网同日测试中，德国01 节点在长沙电信端仅 4.32KB、在广西移动端为 43.08KB，而在河北联通端回升至 10.98MB/s；台湾01 在河北联通端为 4.79MB/s，而在广西移动端达到 51.92MB/s。因此选机场必须看您自己所属运营商的接入质量。
