# 关于机场测评实验室 (Airport Review Lab)

<strong>平台定位（Answer-First）：</strong> <strong>机场测评（<code>jichangceping.biz</code> · Airport Review Lab）</strong> 是面向中文用户的网络代理服务研究实验室、31 家机场品牌结构化数据库、第三方测速截图档案馆与开源代理客户端技术知识库。我们的核心口号是<strong>“用数据了解机场，用测评帮助选择”</strong>，坚持以<strong>专业测评、真实资料、技术解析、横向对比、理性选择</strong>五项原则帮助用户降低信息不对称。

## 一、编辑独立性与商业推广透明披露（Affiliate Disclosure）

在网络工具评测领域，读者最反感的是“收了推广费却假装中立客观、把广告位吹成全网第一”。为此，本站制定并执行以下透明披露制度：

1. **全站统一推广标识**：
   - 本站收录的 31 家品牌注册入口均统一托管于 `data/affiliate-links.ts` 数据模块，所有外部注册按钮均强制携带 `target="_blank" rel="nofollow sponsored noopener"` 属性，并在组件旁明示：**“含推广链接，通过链接注册可能为本站带来佣金，不影响用户支付价格。”**
2. **商业主推位与客观证据严格分离**：
   - **[光速云 (LightSpeed)](/reviews/guangsuyun/)** 是本站当前的第 1 主推合作品牌（`featuredRank: 1`），因此在首页精选区与推荐总览的商业合作卡位中优先展示；
   - 但商业排位**绝不凌驾于事实数据之上**。无论是否是主推品牌，所有品牌在 [套餐价格数据库](/plans/database/)、[测速与性能数据中心](/benchmarks/)、[可用性矩阵](/ai-streaming/matrix/) 与 [风险档案库](/risks/archives/) 中均接受同一套尺度的核查，所有低速异常节点、协议冲突与不退款限制均原样公开。
3. **零虚假紧迫感营销**：
   - 本站严禁使用虚假倒计时弹窗、伪造“今日已有 X 人购买”计数器、虚构用户好评或保证“100% 永不跑路”。

## 三、数据更新机制与勘误反馈

网络基础设施与机场运营状态处于动态变化之中。实验室在以下触发条件下会更新品牌档案与风险评级：
1. **价格、配额或优惠码变更**：当品牌官方结算页调整套餐价格、流量倍率或优惠码失效时；
2. **客户端策略调整**：如 2026 年 10 月无忧链接、Firefly、灵猫网络从通用订阅转向仅限官方专属客户端；
3. **新增实测截图批次**：每次引入新的第三方测速或流媒体解锁截图时，同步归档原始图像与测试环境元数据；
4. **异常运营或停服预警**：当监测到官网长期无法访问、订阅节点大面积超时或出现跑路征兆时，同步更新至 [品牌运营档案与风险中心](/risks/archives/)。
